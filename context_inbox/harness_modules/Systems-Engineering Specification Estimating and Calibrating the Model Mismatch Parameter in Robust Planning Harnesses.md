### Systems-Engineering Specification: Estimating and Calibrating the Model Mismatch Parameter ($\epsilon_0$ / $\rho$) in Robust Planning Harnesses

In distributionally robust online planning architectures (such as **Wasserstein-MCTS** or **Robust Sparse Sampling**), the model mismatch parameters—specifically the baseline model error **$\epsilon_0$** in W-MCTS and the uncertainty budget **$\rho$** in Robust Sparse Sampling—serve as the mathematical foundation of the uncertainty sets. 

If these parameters are underestimated, the resulting ambiguity sets will fail to cover the true physical transition distribution, exposing the agent to catastrophic out-of-distribution (OOD) blunders. Conversely, overestimating them forces the planner into extreme, hyper-conservative behaviors, sacrificing average-case utility and efficiency.

This specification details the reverse-engineered systems-engineering techniques, isomorphic frameworks, and calibration strategies used to define and estimate these critical mismatch parameters.

#### 1. Automated Discovery and Constraint Mining
Parameterizing model mismatch requires separating the estimation boundary into **hard invariants** and **soft optimizable targets**:

*   **Hard Boundaries (Invariants):**
    *   **The Probability Coverage Limit:** The mismatch parameter must be large enough to guarantee that the true transition dynamics $P^*$ fall within the uncertainty set with high probability ($P^* \in \mathcal{P}$), satisfying the PAC safety constraint.
    *   **Dimension-Free Scaling (For continuous states):** For continuous state spaces, the complexity of solving the robust planner must scale independently of the raw state cardinality, making parametric estimation dependent only on transition metrics.
*   **Soft Targets (Optimizable Goals):**
    *   **Minimizing the Conservatism Gap:** Adapting the baseline error dynamically so the agent does not default to "lazy" or defensive play in low-risk, well-modeled regions of the state space.
    *   **Asymptotic Decay Calibration:** Ensuring the state-dependent radius $\epsilon_s = \epsilon_0 / \sqrt{N(s)}$ shrinks at a rate that matches the convergence of the empirical transition function to the true physical landscape.

#### 2. Isomorphic Formalization (From Discrepancies to Parameters)
To estimate the mismatch parameters from real-world data, engineers leverage two primary mathematical frameworks depending on the geometry of the state space:

##### Method A: Manifold Discrepancy Mapping (For $\epsilon_0$ in Wasserstein Space)
In continuous or high-dimensional environments (such as robot kinematics or physical-system trajectories), the baseline model error **$\epsilon_0$** is estimated by measuring the distance between simulated and physical trajectories.
1.  **Trajectory Manifold Extraction:** Let $\tau_{\text{sim}} \sim P_{\text{sim}}$ be trajectories generated by the learned transition model, and $\tau_{\text{real}} \sim P_{\text{real}}$ be matching trajectories executed on the physical system.
2.  **Wasserstein Discrepancy Measurement:** The parameter $\epsilon_0$ is estimated by calculating the first-order **Wasserstein distance ($W_1$)** between the empirical distribution of simulated state transitions ($\hat{P}$) and the true transition dynamics ($P$):
    $$\epsilon_0 \approx \mathbb{E} \left[ W_1(\hat{P}, P) \cdot \sqrt{N(s)} \right]$$
    This directly binds the parameter to the physical discrepancy between the simulator and the real-world environment.

##### Method B: Statistical Confidence Intervals (For $\rho$ in Total Variation Space)
In discrete or partitioned state-action spaces (such as grid-worlds or logic-state networks), the mismatch parameter **$\rho$** represents the maximum **Total Variation (TV) distance** between the estimated and true transition kernels:
1.  **Abduction and Estimation:** The approximate generative model $P^o$ is estimated from empirical transition counts.
2.  **Statistical Bound Formulation:** By applying concentration inequalities (such as the Berend-Kontorovich bounds), $\rho$ is estimated with a confidence level $1-\delta$:
    $$\mathbb{P} \left( D_{\text{TV}}(P_{s,a}, P^o_{s,a}) \le \rho \right) \ge 1-\delta$$
    This approach allows $\rho$ to be derived directly from the statistical confidence of the collected dataset.

#### 3. Parametric Trade-off Modeling
Selecting the magnitude of $\epsilon_0$ or $\rho$ places the AI system along a strict **performance-robustness frontier**:

```
Conservative Safety (Zero Failure Rate)
      ▲
      │                              ● [High ε_0: Robust Conservative Mode]
      │                                - Guarantees PAC tail-safety
      │                                - Sacrifices performance in low-risk zones
      │                                - High regret bound overhead
      │
      │                  ● [Optimized ε_0: Calibrated Hybrid Mode]
      │                    - State-action dependent calibration
      │                    - Applies robust constraints selectively
      │
      │                                       ● [Zero/Low ε_0: Nominal Mode]
      │                                         - High empirical returns in sim
      │                                         - Catastrophic collapse under drift
      └────────────────────────────────────────────────────────► Operational Efficiency
                                                                 (Discounted Return)
```

*   **The Conservatism Crossover Point:** In low-noise or nominal regimes, a larger $\epsilon_0$ causes the agent to underperform compared to standard, non-robust planners. However, as environmental noise or distributional drift increases, the robust planner maintains stable, flat performance, whereas the non-robust planner experiences a steep drop-off in success rate.
*   **The Non-Stationary Estimation Barrier:** In non-stationary or partially observed environments, accurately estimating $\epsilon_0$ or $\rho$ is **highly non-trivial because transition dynamics evolve over time**. This introduces a trade-off between keeping a static, conservative parameter (which limits performance) and running online parameter estimation (which introduces computational and tracking overhead).

#### 4. Continuous Falsification and Edge-Case Stress Testing
To systematically stress-test and calibrate the estimated $\epsilon_0$ or $\rho$ parameter in a production-grade AI planning harness, the system must deploy active falsification checks:

*   **The "State-Action Dependent" Calibration Test:**
    *   *Implementation:* Rather than applying a uniform global budget, implement a **state-action dependent budget $\rho(s, a)$ or $\epsilon_s(s, a)$**. Apply the robust backup update exclusively in high-uncertainty regions (e.g., a localized "hazard zone" characterized by high-noise variance), while using standard expected value backups in highly familiar, data-rich states.
    *   *Verification:* Measure the success rate across varying noise standard deviations ($\sigma_{\text{high}}$) in the hazard zone. If the agent experiences constraint violations, the local budget parameter must be scaled up.
*   **The Conformal Region Intersection Audit:**
    *   *Implementation:* Construct **Conformal Prediction (CP) regions** around simulated trajectory sequences at a specified confidence level $1-\delta$. 
    *   *Verification:* Intersect these confidence regions with the Wasserstein planning radius ($\epsilon_s$). If the physical trajectories fall outside the intersection, it mathematically falsifies the current baseline error estimate ($\epsilon_0$), triggering an automated update to expand the ambiguity set.
