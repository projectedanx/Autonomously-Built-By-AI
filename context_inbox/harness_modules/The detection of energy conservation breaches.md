The detection of energy conservation breaches in physically based rendering (PBR) shader code by the `vsc_evaluator.py` tool transitions shader validation from qualitative "vibe testing" into a deterministic, **correct-by-design systems engineering pipeline**.

In a physically based rendering pipeline, materials must respect the **laws of thermodynamics and energy conservation**. Specifically, a surface cannot reflect more light than it receives. This physical invariant is formalized in the Bidirectional Reflectance Distribution Function (BRDF) as:

$$\text{Reflected Energy} = \text{Diffuse Component} (\text{kD}) + \text{Specular Component} (\text{kS}) \le \text{Incoming Energy} (1.0)$$

Where:
*   $\text{kS}$ represents the specular reflection fraction, which is calculated dynamically using **Schlick's Fresnel approximation** ($F$).
*   $\text{kD}$ represents the diffuse reflection fraction, representing light that penetrates the surface, scatters, and exits.

To prevent energy leaks (which cause rendering artifacts like physically impossible "glowing" surfaces under global illumination), the diffuse reflection factor must be scaled dynamically by the remaining unreflected energy:

$$\text{kD} = 1.0 - F$$

### The AST and Symbolic Analysis Engine: How the Parser Operates

The `vsc_evaluator.py` engine implements a **static shader analyzer** that parses GLSL source files to construct a symbolic representation of the mathematical operations. The parser decomposes the shader code to enforce **VCS Layer 3 (Semantic Layer)** constraints. 

```
                          [ Raw GLSL Code ]
                                  │
                                  ▼
                     [ Lexical Tokenization ]
            Identifies variables, vectors, operations
                                  │
                                  ▼
                   [ Mathematical Graph Extraction ]
            Constructs a symbolic dependency tree
                                  │
                                  ▼
              [ PBR_INV_01_ENERGY_CONSERVATION Check ]
        Asserts that the diffuse factor is scaled by (1.0 - F)
                                  │
         ┌────────────────────────┴────────────────────────┐
         ▼                                                 ▼
     [ Compliant ]                                 [ Non-Compliant ]
  F_s = 1.0 (Passes)                             AST Violation Detected
                                                 Calculates VSC penalty
                                                 Triggers Epistemic Escrow
```

The parser executes this validation through a three-stage pipeline:

#### Stage 1: Lexical and Scope Tokenization
The parser isolates code blocks representing BRDF integration (such as Cook-Torrance or GGX equations). It sanitizes comments, resolves variable aliases, and extracts key vectors (Normal $N$, View $V$, Light $L$, and Halfway $H$).

#### Stage 2: Assignment and Expression Tracking (Dependency Mapping)
The parser tracks assignments to identify where the **Fresnel coefficient ($F$)** is calculated. It builds a directed dependency graph of all intermediate variables.
*   It looks for Schlick’s Fresnel approximation:
    `vec3 F = F0 + (1.0 - F0) * pow(1.0 - VdotH, 5.0);`
*   It then scans subsequent expressions to locate where the diffuse scaling factor (`kD`) is declared and assigned.

#### Stage 3: Algebraic Invariant Auditing
The parser evaluates the final return expression of the shader. It asserts that if diffuse and specular terms are added, the diffuse term must have been pre-multiplied by a vector or scalar representing $(1.0 - F)$.

### Concrete Code Exemplars: Analyzing the Parser's Gating Logic

#### 1. The Non-Compliant Shader (Energy Conservation Breach)
Consider the following shader code generated by an unconstrained agent attempting to write a simple BRDF:

```glsl
// WARNING: Non-Compliant PBR Shading (Energy Leaking)
vec3 BrokenBRDF(vec3 N, vec3 V, vec3 L, vec3 albedo, float roughness) {
    vec3 h = normalize(V + L);
    float NdotV = max(dot(N, V), 0.0001);
    float NdotL = max(dot(N, L), 0.0001);
    float NdotH = max(dot(N, h), 0.0001);
    float VdotH = max(dot(V, h), 0.0001);

    // Specular Fresnel
    vec3 F0 = vec3(0.04);
    vec3 F = F0 + (1.0 - F0) * pow(1.0 - VdotH, 5.0);

    // Specular lobe calculation (Cook-Torrance)
    float denominator = 4.0 * NdotV * NdotL + 0.0001;
    vec3 specular = F / denominator;

    // Direct addition of raw albedo and specular
    vec3 diffuse = albedo / 3.14159265;
    return diffuse + specular; 
}
```

*   **How the Parser Intercepts the Breach:**
    1.  The parser tracks the variable `specular` and determines it is dependent on the Fresnel term `F` (which represents the specular fraction $\text{kS}$).
    2.  The parser tracks the variable `diffuse` and finds it is assigned `albedo / 3.14159265`.
    3.  It evaluates the return statement: `diffuse + specular`.
    4.  It checks the dependency graph of the `diffuse` variable to verify if it has been scaled by `(1.0 - F)`.
    5.  Since the diffuse term is completely independent of the Fresnel term `F`, the parser flags a violation of **`PBR_INV_01_ENERGY_CONSERVATION`**:
        ```
        PBR_INV_01_ENERGY_CONSERVATION: Directly adding diffuse and specular without Schlick's scale (diffuse + specular) violates energy conservation laws. Must use: diffuse * (1.0 - specular_factor).
        ```
    6.  The **Code Fidelity score ($F_s$)** is penalized, dropping the overall **Value Score of Confidence (VSC)** below `0.85` and triggering **Epistemic Escrow** to freeze execution.

#### 2. The Compliant Shader (Structurally Validated)
To pass the AST quality gate, the shader must explicitly partition the energy:

```glsl
// SUCCESS: Compliant PBR Shading (Energy Conserving)
vec3 CookTorranceBRDF(vec3 N, vec3 V, vec3 L, vec3 albedo, float roughness) {
    vec3 h = normalize(V + L);
    float NdotV = max(dot(N, V), 0.0001);
    float NdotL = max(dot(N, L), 0.0001);
    float NdotH = max(dot(N, h), 0.0001);
    float VdotH = max(dot(V, h), 0.0001);

    // Specular Fresnel
    vec3 F0 = vec3(0.04);
    vec3 F = F0 + (1.0 - F0) * pow(1.0 - VdotH, 5.0);

    // Cook-Torrance Specular Denominator guarded by epsilon
    float denominator = 4.0 * NdotV * NdotL + 0.0001;
    vec3 specular = F / denominator;

    // Energy Conservation (multiply diffuse by 1.0 - F)
    vec3 kS = F;
    vec3 kD = vec3(1.0) - kS;
    vec3 diffuse = kD * albedo / 3.14159265;

    return diffuse + specular;
}
```

*   **How the Parser Validates the Compliance:**
    1.  The parser tracks `specular` (dependent on `F`).
    2.  The parser tracks `diffuse` and finds it is scaled by `kD`.
    3.  It traces `kD` back to its assignment: `vec3(1.0) - kS` where `kS` is assigned `F`.
    4.  The parser verifies that the diffuse fraction is scaled by $(1.0 - F)$.
    5.  The return statement `diffuse + specular` is approved. The parser logs **Perfect structural compliance** and allows the code to proceed to compilation.

### Reducing AI Cognitive Debt

Enforcing these checks at the AST level directly reduces **AI Cognitive Debt**. If an AI agent attempts to generate a shader with an energy leak, the parser intercepts the failure before compilation or runtime visual testing. 

Instead of requiring human engineers to manually debug subtle, complex rendering bugs (like materials looking slightly too bright under specific lighting angles), the parser halts the pipeline, logs the failure to the **Scar Tissue Archive (STA)**, and forces self-correction through **Failure-Informed Prompt Inversion (F-IPI)**.
