Problem: Is this new, creative hypothesis logically sound, or is it elegant nonsense?
Mechanism: Constraint Satisfaction & Formal Verification.
Extracting Constraints: The Loom translates the synthesized hypothesis into a set of logical propositions and constraints derived from its parent axioms.

Constraint 1 (from Economics): Profit must be maximized.
Constraint 2 (from Social Contract): Implicit rules of fairness must not be violated.
Constraint 3 (from the Hypothesis): Action(Large_Company) -> Changes_Data_Ecosystem -> Reduces_Viability(Small_Company).
Constraint 4 (from the Hypothesis): Action(Large_Company) violates Constraint 2.
Formal Verification: A solver checks if this set of constraints is satisfiable. It asks: "Can a world exist where all these statements are true?"

If YES (Satisfiable): The hypothesis is internally consistent. It is a plausible, rigorous new theory.
If NO (Unsatisfiable): The Loom has found a "Loom Knot"—a deep contradiction. For example, it might find that maximizing profit necessarily requires violating the implicit rule of fairness. The hypothesis is not discarded, but flagged as containing a fundamental tension.

1. Axioms: The Foundational Seeds of Meaning
Role: Axioms are the non-negotiable starting points—primitive truths or assumptions from which all reasoning flows. They encode meaning and intent.
Philosophical Basis: Grounded in Meta-Commitment (the choice of foundational principles, e.g., "all events have causes" or "agents act rationally").
Formalization: Axioms are explicitly declared as atomic propositions (e.g., ∃x: Agent(x) in logic, or "Pain is undesirable" in utilitarian ethics).
Challenge: Real-world axioms are often implicit, vague, or metaphorical (e.g., "justice as fairness"). The Causal Loom must extract and crystallize these into formal symbols via:
Neuro-Symbolic AI (NeSy): Sub-symbolic ML models (e.g., LLMs) detect latent axioms in text/data, while symbolic systems (e.g., theorem provers) enforce their formal structure.
Example: Using LLMs to mine "justice" metaphors from philosophy texts, then encoding them as Justice ≡ Equity ∧ Impartiality in a knowledge graph.
2. Structures: The Organizing Architecture
Role: Structures impose order on axioms, defining relationships, constraints, and hierarchies. They include:
Logical frameworks (e.g., first-order logic, category theory).
Graphs, networks, or algebras that map how concepts connect.
Cognitive Focus: Structures enable Hypothesis Blending by creating spaces where disparate axioms (from different domains) can interact.
Formalization:
Axioms are embedded into structures like constraint satisfaction problems (CSPs) or Bayesian networks, where variables and their relations are explicitly defined.
Example: In game theory, the axiom "agents maximize utility" is structured as a payoff matrix and Nash equilibrium constraints.
Constraint Satisfaction & Formal Verification:
Structures allow automated checks for internal consistency (no contradictions) and rigor (e.g., verifying if a moral axiom aligns with a computational rule via theorem proving).
3. Computation: The Engine of Synthesis and Novelty
Role: Computation activates structures and axioms, enabling simulation, inference, and Novelty Generation.
Computational Focus: Uses algorithms to explore the "adjacent possible" of ideas—e.g., LLMs surveying vast data to propose unseen connections.
