# Harness Modules

This directory contains systemic specifications, mathematical formalisms, and abstract research prompts for models.

## PEACE Meta-Architecture
1. Retrieval Module: Extracts task-relevant contextual priors.
2. Cognition Module (System 1): Generates associative hypotheses.
3. Control Module (System 2): Overseer intercepting and parsing into BDI logic.
4. Action Module: Executes commands.
5. Memory Module: Manages state tracking with context trees.
